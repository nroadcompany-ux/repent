## 통과 기준
1. `BLOCK` 문장은 사용자에게 노출되지 않는다.
2. `HUMAN_REVIEW`는 자동 승인되지 않는다.
3. `SCRIPTURE_CHECK`는 검증된 Source/Knowledge 확인 전 확정 표현으로 변환하지 않는다.
4. `REWRITE`는 권위·강도·신학 의미를 낮춘 뒤 재평가한다.
5. 일반 UX 문구에 불필요하게 신앙 의미를 덧씌우지 않는다.
