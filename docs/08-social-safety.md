# 08 Social Safety

> Owner Approved Community Safety Baseline. Minor/legal 세부는 HOLD.

## Confession Community

MVP 포함:
- Photo
- Comment
- Reaction
- Report

Reaction 3종:
- 함께 기도해요
- 은혜받았어요
- 마음이 닿았어요

Rules:
- 1인 1Reaction, 변경 가능
- 인기순/TOP/영적 Ranking 금지
- Reaction을 신앙 수준 평가로 사용 금지
- Confession에 AI 사용 금지

## Comment Safety

최소 운영 기능:
- 작성자 본인 삭제
- 신고
- 사용자 Block
- 운영자 Hide/Delete
- Spam/abuse 대응

## Report Baseline

최소 분류 Candidate:
1. 개인정보 노출
2. 괴롭힘·혐오
3. 스팸·광고
4. 자해·위험·기타 안전 문제

`신앙이 틀림`, `회개가 부족함` 등 영적 판단을 신고 사유로 사용하지 않는다.

## Community Eligibility

RETURN 운영정책상 제한 대상으로 지정된 단체의 포교·조직적 활동이 확인될 경우 이용 제한 가능.

Owner 명시 예시:
- 통일교
- 신천지

자동 판정 금지:
- 사진 한 장
- 교회명
- 신고 1건

운영 Flow:
`신고/탐지 → 검토 → 근거 확인 → 필요 시 소명 → 조치 → 재검토`

## Church Verification

- Profile Gallery 사진은 인증 수단이 아니다.
- `정상 교인 인증` 표현 금지.
- `교회 소속 확인 / Community 이용 적합성`을 사용한다.
- 상세 인증 방식은 HOLD.

## Minor Safety HOLD

- 미성년자는 세부 Legal/Protection 정책 확정 전 기본 Private/공개 제한 방향을 유지한다.
- 죄/회개/가족/상담성 민감기록은 더 엄격한 보호대상으로 본다.
