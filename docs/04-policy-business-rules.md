# 04 Policy Business Rules

> Owner Approved Product/UX Policy. Legal/Launch 세부정책은 HOLD 항목을 별도 유지한다.

## Journey / Mood

- 5단계 자기기록: 매우 힘듦 / 힘듦 / 보통 / 좋음 / 매우 좋음
- No Input = Missing. 점 생성 및 자동 보간 금지.
- 신앙 수준, 하나님과의 거리, 영적 상태로 환산 금지.

## Prayer

- `나의 기도 | 중보기도` Secondary Segment를 항상 노출한다.
- Prayer/Repentance를 재촉하는 Push 기본 제공 금지.
- 응답/미응답, 하나님의 뜻을 시스템이 판정하지 않는다.

## Repentance

- 한글 Primary + 4R 내부 Framework.
- 임시저장 + 이어쓰기 허용.
- Final CTA: `회개 기록 마치기`.
- Progress %, 완료율, 영적 점수 금지.

## Promise / Action

- 기본 그룹: 나의 삶 / 사람과 관계 / 신앙생활
- Promise user-facing finish: `마무리됨`
- Promise 1:N Action
- 이행률은 행동 측정치만 허용.
- Retry / Modify / Reschedule / Record Only / Optional Repent 의미 유지.
- Action Failure ≠ Sin.
- Reminder는 Promise/Action 사용자 설정형만 MVP 허용.

## Confession

- Types exact: 기도 / 고백 / 은혜 / 일상
- Photo + Comment MVP 포함
- 게시물 Photo 최대 1장
- Reaction 3종: 함께 기도해요 / 은혜받았어요 / 마음이 닿았어요
- 1인 1Reaction, 변경 가능
- 인기순, TOP, 영적 Ranking 금지
- AI 사용 금지

## Profile / Community

- Social Login: 네이버 / 구글
- 교회명 / 교단 입력
- 대표 프로필 사진 1장
- Profile Gallery 최대 30장
- Profile / Confession Hashtag 지원
- 교회 활동 사진은 자기표현 자료이며 교인 인증 수단이 아니다.
- 교회명/교단 자동 공개 금지. 공개는 사용자 선택.

## Community Eligibility

- RETURN 운영정책상 제한 대상으로 지정된 단체의 포교·조직적 활동 확인 시 이용 제한 가능.
- 통일교, 신천지는 Owner가 명시한 제한 대상 예시.
- 사진 1장, 교회명, 신고 1건만으로 자동 판정 금지.
- 신고/탐지 → 검토 → 근거 확인 → 필요 시 소명 → 조치 → 재검토.

## Scripture

- Reference 중심.
- Full Text는 License 확보 후에만 제공.
