## Prayer IA

Primary Surface:
- 기도 제목
- 기도문

기도 제목 내부 Secondary Segment:
- 나의 기도
- 중보기도

Hierarchy:
`기도함 → 기도 제목 → 날짜별 기도 기록`

## Repentance IA

한글 Primary Flow:
1. 돌아보기
2. 깨닫기
3. 돌이킴 약속
4. 돌아가기

4R 영어 표현은 내부 Framework 또는 보조표기로만 사용한다.

## Promise IA

- 진행 중 / 마무리됨 / 전체
- 기본 그룹: 나의 삶 / 사람과 관계 / 신앙생활
- Promise Detail 내부에 Action 및 실행 기록

## Confession IA

Types:
- 기도
- 고백
- 은혜
- 일상

Feed / Write / Comment / Reaction / Profile / Report 경로를 포함한다.

## Cross-Domain Loop

Core:
`기도 → 회개 → 약속 → 실행 → 여정`

Community Optional:
`Private Record → User-selected ShareCopy → 고백 → Reaction / Comment`

직접 진입을 허용하며 강제 Funnel로 만들지 않는다.
