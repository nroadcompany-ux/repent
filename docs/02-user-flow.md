# 02 User Flow

> Owner Approved / Planning Locked.

## Authentication / Onboarding

앱 진입 → 네이버/구글 로그인 → Profile 입력 → 교회명/교단 → 약관 → 첫 시작 질문 3개 → Journey Home

Onboarding 중단 시 Resume 가능해야 한다.

## Prayer Flow

Prayer Home → 기도 제목 / 기도문 → 나의 기도 / 중보기도 → 기도함 → 기도 제목 → 날짜별 기록

Prayer Detail 후속:
- 이전 / 다음
- 목록
- 기록 도움
- 약속으로 남기기
- 나누기

## Repentance Flow

돌아보기 → 깨닫기 → 돌이킴 약속 → 돌아가기 → `회개 기록 마치기` → Preview/Review → 저장 또는 계속 수정

- 작성 중 임시저장 허용
- 미완료 기록은 `이어쓰기`
- 저장 후 선택 경로: 복사하기 / 고백으로 나누기 / 약속 보기 / 여정으로 돌아가기

## Promise / Action Flow

Promise Home → 그룹/목록 → Promise Detail → 실행 추가 → Action Record → Retry / Modify / Reschedule / Record Only / Optional Repent → Journey

Action Failure ≠ Sin.

## Confession Flow

Confession Feed → Write → Type 선택 → Body → Photo 선택 → Hashtag → 공개범위 → Preview → Publish

Private Record 공유 시:
`Private Original → 공유 필드 선택 → ShareCopy Draft → Preview → Publish`

## Journey Return Flow

Prayer / Repentance / Promise / Action / Scripture / Life Event 기록은 Journey Calendar / Timeline / Search에서 재탐색 가능해야 한다.
