# REPENT — 앱 내용 정리 (ux-v1-2 프로토타입 기준)

> 이 문서는 외부 검토(GPT 등)에 보내기 위해 프로토타입의 내용을 한 파일로 정리한 것이다.
> **상태: NON-CANONICAL / UX VALIDATION / Owner 검수 전.**
> 확정 사양은 저장소의 `docs/final/01~10`이며, 이 문서와 충돌하면 그쪽이 우선한다.
>
> 프로토타입 주소: https://repent-app.vercel.app/prototype/ux-v1-2/index.html

---

## 1. 이 앱은 무엇인가

개인이 **기도 · 약속 · 실행 · 회개 · 고백**을 기록하고, 그 기록이 시간이 지나며
하나의 여정으로 쌓이는 앱이다. 주 사용자는 40~60대, 특히 여성을 우선 고려한다.

한 문장 구조(Golden Loop):

> 기도하고 → 마음에 남은 약속을 적고 → 작은 행동으로 살아보고 →
> 필요하면 돌아보고 회개하고 → 원하면 나누고 → 모든 순간이 여정에 쌓인다.

각 화면은 항상 세 가지를 보여준다: **내가 어디서 왔는지 / 지금 무엇을 하는지 /
다음에 어디로 갈 수 있는지.**

## 2. 화면 구조

### 상단 바
다섯 탭 화면 모두 **진한 보라 브랜드 바**를 쓴다. 왼쪽에 앱 이름 `REPENT`,
오른쪽에 **햄버거 메뉴**(사용법 다시 보기 / 앱 내용 내려받기 / 공지 / 문의 / 설정)와
**마이페이지**(프로필, 내 기록 모아보기, 개인정보와 공개 범위, 알림, 계정)가 있다.
하위 화면은 흰색 바에 뒤로가기와 화면 이름을 쓴다.

### 하단 탭 5개
`여정` · `기도` · `약속` · `회개` · `고백`

- **Today는 탭이 아니다.** 여정 안의 한 영역이다.
- **검색도 탭이 아니다.** 여정 안의 기능이다.
- **실행(Action)은 탭이 아니다.** 약속 상세 안에서 추가·관리한다.

### 첫 진입
가입이나 질문 없이 **바로 여정(홈)** 으로 들어간다. 홈 위에 반투명 **코치마크가
7단계**로 뜬다: 인생 그래프 → 기도 탭 → 약속 탭 → 회개 탭 → 고백 탭 → 여정 탭 →
"기도 한 줄부터 시작해볼까요?". 건너뛸 수 있고, 여정 앱바의 `?` 로 다시 볼 수 있다.

> 이전 안이었던 "가입 직후 3개 질문"은 **제거**했다. 첫 화면에 빈 입력창 3개가
> 있으면 목적 설명을 붙여도 부담이 남는다. 대신 그 질문들을 홈의 **오늘** 영역으로
> 옮겨, 강요가 아니라 초대가 되게 했다.

## 3. 여정 (홈)

순서: 날짜 → **인생 그래프** → **오늘** → 지나온 순간 → 터닝포인트 → 최근 기록 → 찾기

### 3-1. 인생 그래프
- **화면 좌우 끝까지 쓰는 풀폭**이며 세로도 깊게 잡는다. 좌우로 스크롤하는 생애
  타임라인으로, 열면 **오늘 위치**에서 시작해 왼쪽으로 과거로 간다.
- 생애 사건이 점으로 찍히고 **곡선으로 이어진다.** 시대 구간(유년기/청소년기/
  대학·청년/결혼/이후)이 배경 밴드로 구분되고, 오늘 자리에 점선이 있다.
- **네 가지 계열**을 겹쳐 볼 수 있다. 그래프 위 칩으로 켜고 끈다.
  - `사건` — 기본 실선
  - `감정` · `신앙` · `재정` — 점선 + 점으로 겹쳐 표시
- **점을 누르면 그때를 자세히 보고 기록하는 화면**이 열린다. `그날의 생각`과
  `지금 돌아보면`을 직접 쓰고, 네 계열의 그때 상태를 5단계 중에서 고른다
  (많이 힘들었어요 / 힘들었어요 / 보통이었어요 / 좋았어요 / 많이 좋았어요).
  음성 기록과 비공개 안내도 같은 화면에 있다.
- 그래프 아래에 같은 사건이 **텍스트 목록**으로도 나열되며, 눌러도 같은 화면이 열린다.
- 화면 고정 문구: *"위아래 높낮이는 그때 스스로 어떻게 느꼈는지를 본인이 직접 표시한
  것입니다. 앱이나 AI가 계산하거나 평가하지 않으며, 신앙의 수준을 재는 점수가
  아닙니다. 숫자나 눈금을 두지 않은 것도 그 때문입니다."*

> **신앙 계열에 대한 주의.** 신앙을 그래프로 그리는 것은 Faith Score 금지와 맞닿는
> 지점이다. 그래서 (1) 값은 전부 사용자가 직접 고르고, (2) 앱과 AI는 어떤 값도
> 계산하거나 해석하지 않으며, (3) 축에 숫자·눈금·점수 라벨을 두지 않고,
> (4) 문구를 "평가"가 아니라 "그때 스스로 어떻게 느꼈는지"로 고정했다.
> 이 항목은 Owner 판단 대상이다.

예시 데이터(40세 여성 기준 13개): 초등학교 입학(7) · 아버지 사업이 어려워짐(12) ·
수련회에서 처음 울며 기도(16) · 대학 입학, 집을 떠남(19) · 어머니 투병(22) ·
첫 직장(25) · 결혼(28) · 첫 아이(30) · 오래 다투던 시기(34) · 이혼(36) ·
다시 교회에 나가기 시작함(38) · 아이와 둘의 일상이 자리잡음(39) · 지금(40)

### 3-2. 오늘
세 개의 유도 카드. 오늘 이미 남긴 것은 흐리게 처리되고 "오늘 남겼어요"로 바뀐다.

| 질문 | 이동 |
|---|---|
| 오늘 하나님께 드리고 싶은 기도가 있나요? | 기도 남기기 |
| 마음에 남아 있는 약속이나 결단이 있나요? | 약속 남기기 |
| 오늘 실천하고 싶은 한 가지가 있나요? | 진행 중 약속의 실행 추가 |

### 3-3. 터닝포인트
설명 배너를 먼저 보여준다:

> **터닝포인트가 뭔가요?**
> 인생 그래프에 이름을 남길 만한 시기를 표시해 두는 기능입니다. 나중에 돌아봤을 때
> "이때부터 달라졌다" 싶은 지점이 그래프에 큰 점으로 남습니다. 표시는 본인만 할 수
> 있고, 언제든 지울 수 있습니다.

### 3-4. 최근에 남긴 기록
`오늘/주/월/해/전체` 범위 선택 + 기록 종류별 레인(기도·기도문·약속·실행·회개·고백)에
**점만** 찍는다. 기록이 없는 날은 아무것도 그리지 않고, 점 사이를 잇지 않는다.

## 4. 기도

상단 세그먼트: **기도 제목** / **기도문**

### 4-1. 기도 제목 (묶음 구조)
상단에 `이번 주 기도` / `전체 기록` 숫자와 최근 맥락 한 줄.
그 아래 6개 묶음 → 묶음을 누르면 제목 목록 → 제목을 누르면 상세.

| 묶음 | 설명 |
|---|---|
| 영혼을 위한 중보 | 아직 예수님을 모르는 이들, 마음이 멀어진 이들을 위해 |
| 가족 | 함께 사는 사람들, 멀리 있는 가족을 위해 |
| 건강 | 몸과 마음의 회복을 위해 |
| 재정과 일 | 생계와 일터, 필요한 것들을 위해 |
| 교회와 사역 | 섬기는 자리와 함께하는 공동체를 위해 |
| 나 자신 | 내 마음과 태도, 하나님과의 관계를 위해 |

제목 목록에는 "38일째 기도하고 있어요"처럼 **기간만** 표시한다.
응답 여부·성공 실패·응답률은 어디에도 없다.

### 4-2. 기도 제목 상세
1. 기도 본문
2. **이 기도의 마음** 세 가지 (사용자가 직접 적음)
   - 하나님께 드리고 싶은 마음 — 내가 내어드릴 수 있는 것
   - 하나님께 받고 싶은 마음 — 지금 구하고 있는 것
   - 천국에서 듣고 싶은 칭찬 — 이 기도가 끝까지 지나간 뒤에
3. **분별 프롬프트** (묶음마다 질문이 다름)
   - 재정과 일: *"지금 필요한 것을 구하는 마음과, 더 갖고 싶은 마음 사이에서 이 기도는 어디쯤에 있나요?"*
   - 영혼을 위한 중보: *"그 사람이 변하기를 바라는 마음에, 내가 편해지고 싶은 마음이 섞여 있지는 않나요?"*
   - 가족: *"가족이 잘되기를 바라는 마음 안에, 내 뜻대로 되기를 바라는 마음은 없나요?"*
   - 건강: *"회복을 구하면서도, 그 시간 동안 하나님과 함께 있기를 구하고 있나요?"*
   - 교회와 사역: *"섬김을 구하는 마음에, 인정받고 싶은 마음이 함께 있지는 않나요?"*
   - 나 자신: *"고쳐달라고 구하는 것과, 고치기로 마음먹는 것 중 지금은 어느 쪽에 가깝나요?"*
   - 공통 꼬리말: *"내가 원하는 결과를 얻으려는 마음인지, 하나님께서 기뻐하실 일을
     구하는 마음인지 — 둘 다 섞여 있어도 괜찮습니다. 모르고 지나가지만 않으면 됩니다."*
   - 고정 주의문: *"이 물음의 답은 본인만 알 수 있습니다. 앱과 AI는 이 기도가 옳은지
     그른지, 욕심인지 아닌지 판단하지 않습니다."*
4. **기도로 그치지 않았는지** — 이 기도에서 나온 약속 / 실행 횟수 / 최근 실행일
5. `이 기도를 약속으로 남기기` / `지금 이 제목으로 기도 기록하기`

### 4-3. 기도문 (대표기도 준비)
> 주일예배 대표기도, 소모임 기도회처럼 **앞에서 기도할 일이 있을 때 미리 써두는 자리**.
> 쓴 기도문은 그대로 쌓여서, 나중에 인생 그래프에서 그때 무엇을 놓고 기도했는지
> 다시 볼 수 있다.

- 자리 선택: 주일예배 대표기도 / 소모임 기도회 / 가정예배 / 식사기도 / 심방·병문안 / 기타
- 제목 + 본문. 다 쓰지 않아도 되고 나중에 이어서 다듬을 수 있다.
- 상세에서 **복사하기**(내 기기 안에서만) / **고백에 나누기**(미리보기 후 직접 게시)
- 기도문도 여정의 기록 마커로 남는다.

## 5. 약속과 실행

> 이 앱의 목적은 **하나님과의 약속을 기억하고 지키는 것**이다. 약속 화면은 그
> 기억과 이행이 눈에 보이는 자리다.

- 상단에 `진행 중 약속` / `마무리된 약속` 숫자 + 최근 맥락 한 줄
- **이행 표**: 약속이 수십 개가 되어도 관리되도록, 카드가 아니라 **행 = 약속 /
  열 = 날짜**인 표로 본다.
  - 왼쪽 **약속 이름 열은 고정**되고, 날짜 칸만 **좌우로 스크롤**된다
  - 맨 위 한 줄이 날짜·요일 헤더이며 모든 약속 행에 그대로 적용된다
  - 열은 **최신순**으로, 맨 왼쪽이 오늘이고 30일까지 거슬러 볼 수 있다
  - 칸을 누르면 그날 지켰다는 표시가 켜지고 다시 누르면 꺼진다
  - 진행 중인 약속이 위, 마무리된 약속이 아래. 마무리된 약속은 새로 체크되지 않고
    지난 표시만 흐리게 남는다
  - 이름을 누르면 그 약속의 상세로 들어간다
- 지킨 날은 채운 동그라미, 표시 없는 날은 **빈 동그라미**다. X 표시도, 빨간색도,
  경고도 쓰지 않는다. **연속 며칠 지켰는지는 세지 않는다.**
- 화면 문구: *"지킨 날을 눌러 표시해 두세요. 표시가 없는 날을 잘못으로 기록하지
  않습니다."*

### 5-1. 약속 상세
- **이 약속을 하게 된 이유** — `어떤 상황이었나요`(계기)와 `무엇을 위한 약속인가요`
  (목적)를 적어둔다. 나중에 왜 이 약속을 했는지 다시 볼 수 있게 하기 위한 자리다.
- **기한(선택)** — 날짜를 정하면 **D-day**와 함께, 지나온 기간 중 표시한 날의 비율을
  보여준다. 예: `D-18 · 9월 24일까지 · 61% · 23일 중 14일 표시`
  - 분모는 **이미 지난 날만** 센다. 남은 날은 계산에 넣지 않는다.
  - 문구: *"지나온 기간 중 지켰다고 표시한 날의 수입니다. 잘하고 못하고를 재는
    점수가 아니며, 남은 날은 계산에 넣지 않습니다."*
  - 기한이 없으면 아무것도 계산하지 않는다.
- 14일치 체크, 오늘의 실행 입력, 실행 기록, `이 약속 돌아보기`가 이어진다.
- **실행은 별도 기능이 아니라 약속 상세 안에 쌓이는 기록**이다.
  약속 상세에 "오늘 할 수 있는 한 가지" 입력이 바로 있다.
- 실행이 0개여도 약속은 그대로 유효하다.
- 사용자가 끝내는 표현은 **`마무리됨`** 이며, 작은 배지로만 쓴다.

금지: 연속 달성 표시, 달성률, 지키지 못한 것을 잘못으로 기록하는 것.

## 6. 돌아보기 (Reflection)

실행을 남긴 직후 또는 약속에서 진입한다. 첫 문장은 성공/실패를 묻지 않는다.

> 오늘 이 약속을 어떻게 살아냈나요?
> 잘했는지 못했는지를 묻지 않습니다. 하지 못한 이유도 묻지 않습니다.
> 다음에 무엇을 하고 싶은지만 고르면 됩니다.

선택지 4개: `기록만 남기기` / `다시 시도하기` / `약속 수정하기` / `회개 기록으로 이어가기`

**"왜 못 했는지"를 묻는 항목은 없다.** 회개로 가는 것은 사용자가 직접 고를 때만이며,
자동으로 회개 기록이 만들어지지 않는다.

## 7. 회개

상단에 `이번 달 회개 기록` / `전체 기록` 숫자 + 최근 맥락.
실행에서 이어져 들어오면 상단에 출처가 작게 남고, 회개 탭에서 직접 들어오면
과거 기억·사건을 자유롭게 꺼낼 수 있다.

네 영역 (번호와 진행률은 화면에 표시하지 않는다):

1. **죄를 돌아보기** — *"오늘 어떤 죄를 돌아보게 되었나요? 오늘 일이 아니어도 됩니다.
   오래 마음에 남아 있던 기억이나 사건도 지금 꺼낼 수 있어요."*
2. **구체적으로 돌아보기** — *"그 죄와 관련해 어떤 말이나 행동, 태도를 돌아보게 되었나요?"*
3. **새롭게 깨달은 것 (선택)** — *"이 일을 돌아보며 무엇을 새롭게 깨닫게 되었나요?"*
4. **돌이키기** — *"앞으로 어떻게 돌이키고 싶나요? 오늘부터 할 수 있는 것 하나면 충분합니다."*

선택 추가: **말씀 참고하기**(Book/Chapter/Verse 후보만, 본문 전문은 라이선스 확보 전
미제공) / **약속으로 남기기** / **실행 추가하기**

최종 버튼: **`회개 기록 마치기`**
고정 문구: *"네 가지 모두 적지 않아도 됩니다. 순서를 지키지 않아도 되고, 도중에 마쳐도
괜찮습니다. 마치기는 기록을 남기는 것이며, 회개의 충분함이나 용서 여부를 판단하지
않습니다."*

마친 뒤 **선택적으로** "이 기록의 일부를 나누고 싶나요?"가 뜬다. 자동 공유는 없다.

## 8. 고백 (공유 화면)

- 피드 우선 구조. 상단 세그먼트 `전체` / `내 기록`
- 게시물: 아바타 + 이름(또는 이름 비공개) + 시간 + 넓은 본문 + 종류 태그 + 공감 1종
- 컴포저는 피드 맨 위의 한 줄(`나도 이야기를 남겨볼까요?`)이며 화면을 차지하지 않는다
- 종류: 기도 / 고백 / 은혜 / 일상
- 공개 범위 3가지: **나만 보기 / 이름 가림 / 이름 공개** — 익명 게시는 없다
- 최신순으로만 보이며, 공감 수로 줄 세우지 않는다
- **사진**: 한 장까지 첨부할 수 있다. 작성 화면에 *"얼굴이나 개인정보가 담긴 사진은
  피해 주세요"* 를 함께 두고, 올리기 전 미리보기와 빼기를 제공한다
- **댓글**: 게시물마다 댓글을 달 수 있다. 댓글 화면 상단에 안내를 고정한다 —
  *"판단하거나 조언하려 하지 않아도 됩니다. 읽었다는 것만 전해도 충분합니다."*

### ShareCopy (사본 나누기)
회개 기록이나 기도문에서 **고른 항목만** 사본으로 만들어 고백에 올린다.
미리보기로 무엇이 보이는지 확인한 뒤 직접 게시한다.
원본과 사본은 분리되어, 원본을 고쳐도 사본은 바뀌지 않는다.
원본을 지울 때는 사본을 남길지 함께 지울지 **사용자가 고른다**(자동 연쇄 삭제 없음).

## 9. 음성 기록

기도 · 회개 · 고백 · 기도문 작성 화면에 있다. 현재 프로토타입은 **작동법 안내만**
보여준다.

> **음성으로 남기기** — 최대 1분 · 짧게 한 마디면 충분합니다
> - 버튼을 누르면 녹음이 시작되고, 다시 누르면 멈춥니다.
> - 1분이 되면 자동으로 멈춥니다.
> - 녹음은 글과 함께 이 기록에 붙어 저장됩니다.
> - 저장 전에 다시 듣고 지울 수 있습니다.

## 10. 비공개 안내

기도 · 회개 · 기도문 작성 화면에 고정으로 노출한다.

> **이 기록은 나만 볼 수 있습니다**
> 앱 운영진을 포함해 다른 어떤 사람도 이 내용을 볼 수 없습니다.
> 내가 직접 나누기를 선택한 부분만 다른 분들에게 보입니다.

고백 작성 화면에서는 공개 범위에 맞춰 다르게 안내한다.

> **여기 쓴 글은 공개 범위에 따라 보입니다**
> 나만 보기를 고르면 앱 운영진을 포함해 누구도 볼 수 없습니다.
> 이름 가림으로 나누면 내용만 보이고 이름은 가려집니다.

## 11. 화면 사이의 연결

| 연결 | 방식 |
|---|---|
| 기도 → 약속 | 저장 후 브릿지 화면. `여기서 마치기`도 같은 크기로 제공 |
| 기도 제목 → 약속 | 상세에서 `이 기도를 약속으로 남기기` |
| 약속 → 실행 | 약속 상세 안에서 바로 입력 |
| 실행 → 돌아보기 | 저장 직후 자동 이동, 4개 선택지 |
| 돌아보기 → 회개 | 사용자가 고를 때만 |
| 회개 → 고백 | 마친 뒤 `일부만 골라 나누기`를 고를 때만 |
| 기도문 → 고백 | 상세에서 `고백에 나누기` |
| 모든 기록 → 여정 | 저장 시 `여정에 남았어요 · 여정에서 보기` 토스트 |

**Return Contract**: 이어서 들어온 화면은 상단에 출처를 작게 유지하고, 저장 후
원래 맥락으로 돌아가는 버튼을 제공한다. 예) 약속 → 실행 → 돌아보기 → 회개로 갔다면
회개 화면에 `약속으로 돌아가기`가 있다.

## 12. 빈 화면을 만들지 않기

기도 · 기도문 · 약속 · 회개 화면에는 **예시 3개**가 먼저 보이고, 그 아래
`내 기도도 적어볼까요?` 같은 버튼으로 작성에 들어간다.

예시(기도): 조급한 마음을 내려놓게 해주세요 / 동생이 다시 교회에 나오기를 /
이번 달 생활비가 채워지기를
예시(기도문): 9월 첫 주 주일예배 대표기도 / 수요 소모임 기도회 인도 /
어머니 생신 가정예배 기도
예시(약속): 매일 아침 10분 먼저 기도하기 / 한 주에 한 번 안부 전하기 /
화가 날 때 한 박자 쉬고 말하기

계속 남아 있는 것 / 교회에서 사람을 겉으로만 대했던 태도

## 14. 절대 만들지 않는 것 (Product Lock)

- 기도 응답 추적 — 응답됨/대기중 상태, 응답률, 기도 성공·실패

- 실패를 죄로 기록하는 것, 자동 회개 생성
- 회개의 고정 단계 수, 진행률 %, 점수, `회개 완료` 표현

- 운영자·AI의 비공개 기록 열람
- AI가 기록의 소유자가 되는 것

AI는 하나님·하나님의 음성·선지자·목회자 대체·영적 심판자·죄의 최종 해석자·

## 16. 검토를 부탁하고 싶은 지점

1. 인생 그래프의 곡선이 "신앙 성장 그래프"로 오해될 위험이 실제로 남아 있는가.
   지금의 문구와 축 처리로 충분한가.
2. 분별 프롬프트가 사용자를 정죄하는 느낌 없이 자기 점검으로 읽히는가.
3. 기도 묶음 6개가 실제 사용자의 기도 생활을 담기에 적절한 분류인가.
4. 코치마크 7단계가 첫 사용자에게 길지는 않은가.
5. 회개 4영역에 번호를 노출하는 편이 이해에 도움이 되는가, 아니면 지금처럼
   번호 없이 두는 편이 나은가.
6. 40~60대 사용자에게 글자 크기와 정보 밀도가 적절한가.
