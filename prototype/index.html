데이터 의미 규칙
Journey 내 기록의 동작 방식
Direct Confession = Live Reference
고백 피드에 직접 작성한 고백은 Live Reference입니다.
수정 시 → Journey에서 최신 내용이 반영됩니다.
삭제 시 → Journey에서도 해당 고백이 제거됩니다.
Private Source → ShareCopy = Snapshot
회개·여정 기록을 공유할 때 복사본(ShareCopy)이 생성됩니다.
Source 수정 시 → 기존 공개본 자동 변경 금지.
ShareCopy는 공유 시점의 스냅샷입니다.
Share Delete ≠ Source Delete
공유본을 삭제해도 원본(Source)은 삭제되지 않습니다.
원본 삭제는 별도의 명시적 행위가 필요합니다.
데이터 흐름
[Private Source]
  ↓ 공유 선택 시
[ShareCopy: Snapshot] → 피드 발행
    ↓ Source 수정해도 ShareCopy 불변
    ↓ ShareCopy 삭제해도 Source 불변

[Direct Post] = Live Reference
  ↓ 수정 시 → 즉시 반영
